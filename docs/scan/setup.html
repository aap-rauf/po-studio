Connect your scan sheet

  1. Create a new private Google Sheet for incoming scans. Keep the existing Store List sheet separate.
  2. In the new spreadsheet open Extensions → Apps Script. Replace the contents of Code.gs with the PO Studio script and save.
  3. Choose Deploy → New deployment → Web app. Set Execute as to yourself and Who has access to Anyone. Deploy and authorize the script. The endpoint checks private keys for reads and writes. Keep the spreadsheet itself private. If your organization blocks anonymous web apps, ask its administrator about this setting.
  4. Reload the spreadsheet. Select PO Studio → Connect desktop and copy the connection details. Paste them into Phone scans → Connect desktop in PO Studio.
  5. Scan the same QR on each phone and choose a store. Bookmark the form in that browser. Phones can submit over mobile data, even with the desktop closed.
  6. On desktop select a store, then open Phone scans. The inbox refreshes every 20 seconds while open. Click Add to PO for the entries you want, then save the draft. Import your product catalog first so PO Studio can match barcodes.

Each QR contains a submission key. Share it only with your scanning team. Keep desktop connection details private. To revoke all devices, disable the web app deployment. Google Apps Script and Sheets usage limits apply.
